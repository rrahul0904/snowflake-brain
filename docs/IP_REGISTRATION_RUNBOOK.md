# Intellectual Property Registration Runbook

**Scope:** U.S.-first protection plan for the platform's original software, study content, question content, and brand.  
**Last reviewed:** 2026-08-21

> Operational guidance only. Final filings, ownership structure, classifications, and enforcement strategy should be reviewed with qualified intellectual-property counsel.

## 1. Do not register Snowflake's marks as our brand

Do **not** file `Snowflake`, `SnowPro`, the Snowflake logo, or a confusingly similar mark as the platform's own trademark.

Before a trademark filing, select a **distinct, ownable platform brand** that does not depend on a third-party mark. Snowflake/SnowPro references should remain descriptive, for example: `Independent preparation for SnowPro Core (COF-C03)` with a clear non-affiliation statement.

The current beta title `Snowflake Certification Platform` should be treated as a descriptive working title, not the recommended trademark filing target.

## 2. Copyright registration — recommended filing set

Copyright exists in qualifying original expression when it is fixed, but U.S. registration creates an official public record and provides important enforcement benefits.

Use the U.S. Copyright Office Registration Portal (`copyright.gov/registration/`) and eCO.

### Filing A — software / source code

Register the copyrightable source code for a stable release of the platform as a computer program.

Prepare:

- exact owner/claimant name;
- author(s) and work-made-for-hire status, if applicable;
- completion/publication dates;
- release/version identifier and Git commit SHA;
- required identifying portions of source code;
- redactions permitted by Copyright Office rules if source contains trade-secret material;
- copyright notice included in the deposit where applicable.

The Copyright Office's computer-program guidance is Circular 61.

### Filing B — written curriculum / study guide

Register the independently authored written guide as a literary work. If multiple separately authored or separately published works are involved, determine the appropriate individual/group/collective-work route before filing.

Maintain a frozen PDF/export and hash of the version being registered so the registered deposit can be mapped back to the exact production content.

### Filing C — original practice-question corpus

The question stems, answer choices, explanations, and original selection/arrangement may contain copyrightable expression. Register the corpus using the filing route appropriate to its publication status, authorship, and structure.

Do **not** assume a question bank is a `secure test`. Copyright Office Circular 64 states that a database or test bank does not qualify as a secure test merely by being a bank. Use secure-test procedures only for qualifying specified secure tests/test-item groups that satisfy the Office's requirements.

For each registered corpus, preserve:

- corpus version;
- SHA-256/hash;
- creation/review dates;
- author/owner records;
- source-provenance manifest;
- publication status/date;
- exact deposit copy.

### Filing D — major original visual assets, if material

If the platform develops valuable original illustrations, diagrams, icon systems, or other visual art separate from the software/content registration, evaluate separate visual-arts registration where useful.

## 3. Current U.S. Copyright Office filing fees

As of 2026-08-21, the Copyright Office's current regulations list:

- electronic Single Application: **$45** where its strict eligibility requirements are satisfied;
- other electronic original-work filings / Standard Application: **$65**.

Fees and procedures can change. Confirm the fee on `copyright.gov` immediately before filing.

## 4. Trademark registration — own brand

Use the USPTO Trademark Center (`trademarkcenter.uspto.gov`) for a U.S. federal application.

### Before filing

1. Pick a distinctive platform name and logo that do not use Snowflake/SnowPro as the source-identifying portion of the mark.
2. Search the USPTO trademark database and the wider web for confusingly similar marks.
3. Confirm who owns the mark: individual or legal entity.
4. Determine whether the application is based on current use in commerce or bona fide intent to use.
5. Identify the goods/services precisely.
6. Preserve specimens showing real trademark use, if filing on a use basis.

Likely areas to discuss with counsel include education/training services and software/SaaS services; the correct International Classes and wording depend on the actual commercial offering and must not be guessed solely from this runbook.

### Fee

As of 2026-08-21, USPTO's base electronic application fee is **$350 per class**, with possible additional fees depending on how the goods/services identification and application are prepared. Confirm current fees before filing.

## 5. Trademark usage rules during launch

Until counsel/clearance confirms the final brand position:

- do not use the Snowflake logo;
- do not imply official certification sponsorship;
- display a clear independent/non-affiliation statement;
- use Snowflake and SnowPro only to identify the technology/certification discussed;
- use the platform's own distinct brand more prominently than third-party marks;
- do not use ® on our own mark until it is federally registered; TM may be used for an asserted unregistered brand where appropriate.

## 6. DMCA designated agent — only if the product hosts user material

If the commercial service allows users to upload, post, store, or publicly share material and the operator intends to rely on U.S. DMCA safe-harbor provisions, evaluate registration of a designated agent through the Copyright Office's DMCA Designated Agent Directory.

Operational prerequisites include:

- designated-agent contact details published publicly on the service;
- matching agent registration with the Copyright Office;
- an actual notice-and-takedown workflow;
- repeat-infringer and related compliance procedures where applicable;
- timely maintenance/renewal of the designation.

This is separate from registering our own copyrights.

## 7. Ownership paperwork before filing

Before any application, confirm the chain of title.

For every material contributor, record whether the work was:

- created personally by the owner;
- created by an employee within employment scope;
- a work made for hire where legally valid;
- assigned to the owner in writing;
- licensed rather than assigned.

If ownership is split or ambiguous, resolve it before claiming sole ownership in a government filing.

## 8. Evidence package to preserve

For each major release keep an immutable registration packet containing:

- Git commit/tag;
- source archive hash;
- curriculum/question-bank hash;
- authorship list;
- contributor agreements;
- provenance report;
- screenshots of public release and copyright notice;
- publication date evidence;
- submitted Copyright Office deposit;
- registration application/receipt/certificate;
- trademark search notes, application, specimens, and registration documents.

## 9. Recommended filing order

1. **Choose the independent platform brand and legal owner.**
2. **Run trademark clearance** before investing heavily in the name.
3. Freeze and hash a stable software/content release.
4. File copyright for the core software.
5. File copyright for the written curriculum.
6. File the appropriate copyright claim(s) for the original question corpus / qualifying tests.
7. File the trademark application for the independent brand.
8. Add DMCA designated-agent registration only if the service model makes it relevant.
9. Repeat copyright registration for materially new releases/corpora as the product evolves.

## 10. Launch blockers

Do not represent the product as fully IP-registered until the applicable filings have actually been submitted/registered. Before commercial launch also replace generic operator language in public legal notices with the exact copyright owner/legal entity and publish a dedicated IP/copyright contact channel.
